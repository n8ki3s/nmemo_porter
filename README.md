**네이버 메모를 Markdown으로 백업하고, 그 백업을 다시 네이버 메모로 가져옵니다.**

`nmemo_porter`는 네이버 메모와 네이버 블로그 글을 Markdown 파일로 저장하고, 메모 백업을 지금 로그인된 네이버 계정의 메모로 다시 만드는 Chrome 확장 프로그램입니다. 계정을 옮기거나, 지운 메모를 되살리거나, 메모를 안전하게 보관할 때 쓸 수 있습니다. 로그인된 브라우저 안에서만 동작하며 별도 서버나 Python 스크립트가 필요 없습니다.

> 블로그 글을 Markdown으로 내려받는 기능도 함께 들어 있습니다. (블로그 가져오기는 지원하지 않습니다.)

## 한눈에 보기

| 항목 | 설명 |
| --- | --- |
| 백업 대상 | 네이버 메모, 네이버 블로그 |
| 가져오기 대상 | 네이버 메모 (이 확장으로 만든 메모 백업) |
| 백업 형식 | 하나의 `.md` 파일 또는 메모별 `.md`를 담은 `.zip` |
| 실행 방식 | Chrome 확장 프로그램 (Manifest V3) |
| 데이터 처리 | 브라우저 안에서 처리, 외부 서버 없음 |

## 주요 기능

- **메모 백업**: 메모 목록을 순회하며 제목, 생성일시, 수정일시, 폴더, 본문, 메모 ID를 Markdown으로 저장합니다.
- **정확한 생성일시**: 화면에 보이는 수정 시각이 아니라 네이버 메모 데이터의 실제 생성일시를 기록합니다.
- **제목 없는 메모 유지**: 제목이 없는 메모는 백업과 가져오기 모두에서 제목 없이 다룹니다.
- **메모 가져오기**: 백업한 `.md`/`.zip`을 지금 로그인된 네이버 계정에 원래 순서대로 다시 만듭니다.
- **중복 방지**: 이미 가져온 메모는 기록해 두었다가 다음 가져오기에서 건너뜁니다. 기록은 언제든 지울 수 있습니다.
- **블로그 다운로드**: 블로그 글의 제목, 날짜, 카테고리, 공개 범위, 본문을 Markdown으로 정리합니다. 공개 범위와 카테고리를 골라 저장할 수 있습니다.
- **저장 방식 선택**: 하나의 Markdown 파일 또는 폴더별 개별 파일을 담은 ZIP 중에서 고를 수 있고, 파일 이름도 바로 바꿀 수 있습니다.

## 설치 방법

1. 이 저장소를 내려받거나 압축을 해제합니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. `nmemo_porter` 폴더를 선택합니다.

> 확장을 설치하거나 업데이트(새로고침)한 뒤에는 **열려 있는 네이버 메모 탭을 한 번 새로고침**하세요. 그래야 생성일시를 읽을 수 있습니다.

## 사용 방법

### 메모 백업

1. 네이버에 로그인하고 `https://memo.naver.com/?viewType=LIST`를 엽니다. 이미 열려 있었다면 새로고침합니다. 다른 탭에서 확장을 실행했다면 팝업의 **네이버 메모 열기**를 눌러도 됩니다.
2. Chrome 툴바에서 확장 프로그램을 실행합니다. 네이버 메모 탭에서 실행해야 저장 방식과 내보내기 버튼이 나타납니다.
3. 저장 방식과 파일 이름을 확인한 뒤 내보내기 버튼을 누릅니다. 버튼 이름은 저장 방식에 따라 **마크다운(.md) 내보내기** 또는 **마크다운(.zip) 내보내기**로 바뀝니다.
4. 모든 메모를 한 번씩 열어 읽은 뒤 파일이 다운로드됩니다. 메모가 많으면 시간이 걸립니다.

생성일시를 일부 메모에서 읽지 못하면 완료 메시지에 몇 개를 확인했는지 알려 줍니다. 이 경우 네이버 메모 탭을 새로고침한 뒤 다시 내보내 보세요.

### 메모 가져오기

1. 메모를 만들 네이버 계정으로 로그인합니다. 가져온 메모는 **지금 로그인된 아이디**에 만들어집니다.
2. 확장 팝업 아래쪽의 **가져오기** 영역에서 **백업 파일을 메모로 가져오기**를 누릅니다. 이 버튼은 네이버 블로그 탭에서는 보이지 않으므로, 네이버 메모 탭이나 다른 탭에서 팝업을 여세요.
3. 열린 페이지에서 백업 `.md` 또는 `.zip` 파일을 고릅니다. 찾은 메모 수와 목록을 미리 볼 수 있습니다.
4. **1개만 먼저 테스트**로 메모 하나를 만들고, 네이버 메모에서 제목·본문·줄바꿈이 제대로 들어갔는지 확인합니다.
5. 문제가 없으면 **모두 가져오기**를 누릅니다. 진행 중에 **중지**할 수 있고, 다시 누르면 남은 메모부터 이어서 가져옵니다.

가져오기 옵션:

| 옵션 | 설명 |
| --- | --- |
| 원래 생성일시를 본문 맨 끝에 적어 두기 | 본문 끝에 빈 줄 하나를 두고 `[2024.03.10.(일) 오전 09:43]`처럼 남깁니다. |
| 이미 가져온 메모는 건너뛰기 | 이 브라우저에서 가져온 적 있는 메모를 제외합니다. |
| 기록 지우기 | 가져온 기록을 지웁니다. 잘못 가져온 메모를 지우고 처음부터 다시 가져올 때 씁니다. |
| 네이버 아이디 | 보통은 비워 둡니다. 가져오기가 실패할 때만 입력해 보세요. |

### 블로그 다운로드

1. 네이버에 로그인하고 `https://blog.naver.com/MyBlog.naver` 또는 백업할 블로그를 엽니다. 팝업의 **네이버 블로그 열기**를 눌러도 됩니다.
2. Chrome 툴바에서 확장 프로그램을 실행합니다.
3. 공개 범위와 카테고리, 저장 방식을 고른 뒤 내보내기 버튼(**마크다운(.md) 내보내기** 또는 **마크다운(.zip) 내보내기**)을 누릅니다.

비공개 글은 해당 블로그 소유자로 로그인되어 있고 목록에서 볼 수 있을 때만 저장됩니다.

## 백업 파일 형식

하나의 파일로 저장하면 메모마다 아래와 같은 구역이 생깁니다. 제목이 없는 메모는 `제목 없음`으로 표시됩니다.

```markdown
---

## 1. 제목 없음

- 날짜: 2024.03.10.(일) 오전 09:43
- 수정: 2025.01.15.(수) 오전 11:37
- 폴더: 내 메모
- 메모 ID: 1234567
- URL: https://memo.naver.com/?viewType=LIST&memoId=1234567

메모 본문
```

- `날짜`는 생성일시, `수정`은 생성 후 고친 적이 있을 때만 적힙니다.
- `파일별로 (.zip)`를 고르면 폴더별 디렉터리 안에 `날짜_제목_ID.md` 파일이 만들어집니다. 제목이 없는 메모는 본문 첫 줄을 파일 이름에 씁니다.
- 가져오기는 이 형식을 읽습니다. 이전 버전으로 만든 백업(제목 자리에 본문 첫 줄이 들어간 파일)도 제목 없는 메모로 올바르게 가져옵니다.

## 가져오기 동작과 한계

- 메모는 원래 만들어진 순서(메모 ID 순)로 만들어지므로, 목록에서는 원래와 같은 순서로 보입니다.
- 본문은 네이버 메모 에디터와 같은 형식(줄마다 `<div>`)으로 보내서 줄바꿈이 유지됩니다.
- 네이버가 제목을 받지 않으면(너무 길거나 이모지 등) 이모지를 빼거나 길이를 줄인 제목으로 다시 시도하고, 원래 제목은 본문 맨 위에 남깁니다. 끝나면 제목이 바뀐 메모 목록을 보여 줍니다.
- 새로 만든 메모의 작성일은 가져온 날이 됩니다. 원래 생성일시는 본문 끝 기록으로만 남길 수 있습니다.
- 모든 메모는 기본 폴더에 만들어집니다. 원래 폴더는 백업 파일에만 남습니다.
- 이미지는 백업에 링크로만 남기 때문에 다시 올라가지 않습니다.

## 데이터 처리 방식

- **백업**: 열려 있는 네이버 메모·블로그 탭에서 내용을 읽어 브라우저 안에서 Markdown으로 바꾸고, Chrome 다운로드로 내 PC에 저장합니다.
- **생성일시**: 네이버 메모 탭에서 네이버 메모 웹이 이미 받아오는 응답 중 메모 정보(생성일시, 수정일시, 제목)만 읽어 둡니다. 새 요청을 보내거나 페이지를 바꾸지 않습니다.
- **가져오기**: 네이버 메모 탭 안에서 네이버 메모 웹이 새 메모를 저장할 때 쓰는 요청과 같은 방식으로 메모를 만듭니다. 로그인 정보는 브라우저가 그대로 쓰며, 확장이 따로 저장하거나 보내지 않습니다.
- **가져온 기록**: 이 브라우저의 확장 저장소에만 남습니다. 네이버나 다른 기기와 공유되지 않습니다.
- 백업 데이터는 어떤 외부 서버로도 업로드하지 않습니다.

## 알아두기

- 네이버 페이지 구조나 내부 요청 형식이 바뀌면 일부 기능이 동작하지 않을 수 있습니다.
- 블로그 글 이미지는 텍스트 중심 백업을 위해 제외됩니다.
- 이 확장 프로그램은 네이버 공식 제품이 아닙니다.

## 프로젝트 구조

```text
nmemo_porter/
|-- manifest.json      확장 설정
|-- popup.html/css/js  툴바 팝업 (탭에 따라 내보내기·페이지 열기·가져오기 표시)
|-- content.js         네이버 페이지에서 백업·메모 만들기 실행
|-- memo-hook.js       네이버 메모 응답에서 생성일시·제목 읽기
|-- import.html/css/js 메모 가져오기 페이지
|-- memo-parser.js     백업 .md/.zip 읽기와 가져올 메모 만들기
`-- icons/             확장 아이콘
```
